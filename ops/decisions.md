- **2026-11-28 · This run ships three PRs in Nheil's order: A = item 0 (PR #10, in QA), B = Program tab (`agent/program-tab`), C = History tab (`agent/history-tab`).** Why: Nheil queued all three for this run (bug first). Could not check PR states through the GitHub API this run (repo access not enabled for the session); statuses come from the run lead.
- **2026-11-28 · No drag-to-reorder on the Program tab; up and down buttons instead.** Why: in Android and iPhone web views, drag on touch fights page scrolling and needs long-press handling. It is hard to make accessible and can't be verified in jsdom. 44 px up/down buttons do the same job safely. Revisit only with a real-phone test plan.
- **2026-11-28 · The History filters and search narrow only the workout list. The calendar and month summary always show the whole month.** Why: the numbers stay stable and easy to trust, and the tests stay simple. Search covers all months, because people search for "when did I last bench".
- **2026-11-28 · Monetization direction (recommended, not final until Nheil confirms):** freemium. Everything shipped today stays free forever (logging, history, backup/sync, all current coaching) and data is never locked. Lift Log Pro holds Nheil's Pro queue. Suggested price: $4.99/mo or $29.99/yr, 7-day trial on yearly only, with honest-trial rules (exact charge date, reminder before it ends, one-tap cancel path). Store billing (Play Billing first, then StoreKit) comes before any web checkout. Why: research shows web links save almost nothing on Android (Google takes 10% even on link-outs), iPhone link-out rules are in court until at least 2027-01-11, and removing free features is what angers users (JEFIT). Free coaching is also our edge against $60–$96/yr coach apps. Nothing paid is built until the Play account, the origin/migration spike and 2 live Pro features exist. Pro features ship free first. Source: `research/monetization.md`. Nheil's 3 questions are under Blocked in `roadmap.md`.
- **2026-11-28 · Android may move from `file://` to `WebViewAssetLoader` only after a localStorage migration test passes, and in its own PR.** Why: the change moves where `liftlog.v1`, `liftlog.auth` and `liftlog.cloud` live, so a careless switch would wipe every user's log. The item 5 vibration bridge must keep `file://`.
- **2026-11-28 · Partner cards must say "Lift Log earns a commission" next to the link, not just "Partner".** Why: the FTC FAQ says a label like "affiliate link" alone is not enough (research §5).

A typical user adds fewer than 400 entries a year, so the profile stays small. Revisit if weigh-ins move to a cloud table once Supabase exists.
- **2026-11-24 · Rate-of-loss guidance uses %/wk bands (green 0.25–0.75, yellow 0.75–1, red above 1) and never gives calorie or diet advice.** Why: these are the research consensus for keeping strength (Helms 2014, Garthe 2011), and CLAUDE.md rule 7 applies. The thresholds for the later Cut guard warning are guesses to tune on Nheil's own cut.

## 2026-11-26: Pro feature queue
- **Decision:** Nheil queued five premium features for the future Pro tier, in this order: PR forecast, "Only got X minutes", Cut coach, Ghost race a friend, Velocity Coach. "Gym's packed" mode was not picked.
- **Why:** PR forecast and the time-cap mode are quick, easy to show in short videos, and make Pro feel worth it on day one. Cut coach serves Nheil's Feb cut. Ghost race needs accounts. Velocity Coach is the wow feature but the hardest, so it comes after launch.
- **Monetization direction (discussed, not final):** free app with a Pro subscription later, plus paid programs from Nheil. No ads.

## 2026-11-26: Ads, only as PR Perks and partner cards
- **Decision:** no ad networks. Brands appear only as labelled milestone rewards, one partner card a week after workouts, or sponsored programs, served from a JSON file in our own repo with no tracking. Pro can turn them off.
- **Why:** keeps the no-tracking rule and the premium feel. Rewards at PR moments feel like perks, not ads.
